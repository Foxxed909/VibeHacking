01. The Golden Rule

1. Authorization is absolute. Only ever test an app you own or have explicit written permission to test. Recon included. No exceptions.

2. Start black-box. Attack what you can see from the outside first — that's where externally-reachable, high-severity bugs live. Because the target is your own app, cracking open the source to confirm a finding and write the fix is fair game, not cheating.

05. Quickstart

# 1. spin up the bundled vulnerable target
python testapp/app.py                         # http://localhost:3456/

# 2. deep scan it
python vibe.py scan http://127.0.0.1:3456/

# 3. run the whole ordered kill-chain
python vibe.py attack http://127.0.0.1:3456/ --skip-load

# 4. watch your own app's health (uptime %, latency, flapping)
python TOOLS/noloader.py --url http://127.0.0.1:3456/ --health -t 60s --expect-text ok

# 5. let Claude drive it autonomously
python claude.py http://127.0.0.1:3456/ --objective "auth and secrets"
